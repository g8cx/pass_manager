# ProfitEaters Password Manager — Frontend

Frontend part of a password manager application developed by **ProfitEaters** for personal use.

## About

The project aims to provide a convenient interface for managing passwords and organizing account credentials.

## Tech Stack

- **HTML5** — markup
- **CSS3** — styling
- **Sass (SCSS/Sass)** — CSS preprocessing
- **JavaScript (ES6+)** — application logic
- **ESLint** — code quality and linting

## Development

- Developed by the **ProfitEaters** team.
- Runs locally using **Visual Studio Code Live Server**.
- No build tools or bundlers are currently used.

## Project Status

Work in progress.
